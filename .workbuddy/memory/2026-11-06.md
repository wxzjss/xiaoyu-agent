# 2026-11-06

## 启动慢（16:44 报，17:46 修好）
- 根因：昨天把回收站阈值 7 天→2 天，要压的从 24 个涨到 2335 个（55MB），
  而 compactTrash 是同步的、挂在 server.listen 回调里，把事件循环堵死。
- 修：启动里那段包进 setTimeout 15 秒 + compactTrash 内部按 200 个分批。
- 效果：启动从十几秒 → 3~4 秒。

## 说话挤成一本书（12:58 报）
- 根因：她的发言靠单换行分段，而 markdown 单换行不产生换行，mdInto 全并成一行。
- 修：进 markdown 前把段内单换行升级成空行（带 ``` 的不动）。
- 坑：这行改坏两次，Python 写文件把 `\u0000` / `\n` 变成真实字符 → 整页白屏。
  最后全用 String.fromCharCode 拼，不写正则字面量。
