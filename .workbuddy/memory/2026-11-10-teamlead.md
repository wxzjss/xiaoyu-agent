## 四、两个必须先修的前置隐患

### 4.1 `features.json` 全表固化 → 新功能在老机器上永不出现
**实测**：主人机器 `schemaVersion:5`，**28 个键全写死**，`desktopHands:true` 就在里面。

- 我改 `desktopHands` 的 `defaultOn:false` → **对他完全无效**
- **新加 `team` 只加一行定义 → 永远不生效**

**修法**：`SCHEMA_VERSION` 5→6 + 「只补缺键」的迁移（`src/features.mjs` 或新 `src/feature-migrate.mjs`）。

### 4.2 `subagent` 上下文切换空操作 + signal 串会话
```
runWithToolContext({sessionId:'PARENT'}, () => {
  setToolContext('SUB')            ← subagent 现在这么切
  ctxNow().sessionId → 'PARENT'    ← 空操作
})
```
**嵌套串/丢**：`snap.owner=B`、`signal=B`（跨会话）、`outbox=null`、`stashFile=null`

**最严重后果：B 会话点停止 → `taskkill /T /F` 杀掉 A 正在跑的命令。**

**修法（三件一起做）**：
1. `tools.mjs:126` `merged = {...CTX, ...ctx}` → `base = CTX_STORE.getStore() || CTX`
2. `subagent.mjs:487` `setToolContext` → `runWithToolContext({sessionId:subId, snap:null, outbox:[], signal:自己new}, ...)`
3. `subagentDepth` 进 ALS（现全局共享 → **`spawn_workers` 派 4 件必拒 2 件**）

**验证脚本（现在红的，修好转绿）**：
- `node scripts/check-signal-isolation.mjs` → 12/20
- `node scripts/check-stashfile-turn.mjs` → 7/9
