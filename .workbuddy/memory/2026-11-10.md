#### ⑨ P1 长会话切会话卡 6.8 秒（WINDOW 虚拟化恒不生效）

- **复现**：300+ 轮的会话，切过去要等好几秒。
- **根因**：`src-ui/items.js:342`
  ```js
  let start = Number(getWindowStart(sid)) || 0;
  if (!(start >= 0 && all.length - start >= WINDOW)) start = Math.max(0, all.length - WINDOW);
  ```
  `getWindowStart` 未设时返回 0 → `start=0` → `all.length - 0 >= 40` 几乎恒成立 → `!(true)` = `false` → **不裁剪**，`start` 保持 0，**所有轮次全渲染**。WINDOW=40 完全没生效。
- **修法**：条件是「用户还没手动往前翻」→ 应该判 `start <= 0`：
  ```js
  if (!(start > 0)) start = Math.max(0, all.length - WINDOW);
  ```
  （`LogView.jsx:177` 的「再往前看」用 `merged.start - 100`，只要 start>0 就保留用户选择。）
- **验收**：改完 `npm run build:ui`；造一个 300 轮会话切过去，应瞬间出（只渲染 40 轮）。用 `_tmp/ui-audit/chat.mjs` 那套造数据法。DOM 里 `#log > .msg` 数量应 ≈ 80（40 轮 × 2 条），不是 600。

### 八、找到真正的元凶：`#meta` 状态文本，不是按钮（2026-11-11 00:50 实测）

**元凶是把 638px 宽的 `#meta` 状态文本 + 标题拆成各自一行**，不是按钮太宽。
那一串「飞鱼 deepseek-v4.1-flash · 当前思考强度：高」有 250px 以上，
一旦允许 wrap，它自己就是一行，标题也自己一行。

**实测各方案（`verify-real-fix.mjs`，390px 严格视口）：**

| 方案 | headerH | 聊天区 | 行数 | 溢出 |
|---|---|---|---|---|
| 基线 nowrap | 50 | 794 | 2 | 630 ❌ |
| 仅 `wrap` | **160** | 684 | 4 | 0 |
| `wrap` + 隐藏 `#meta` | **91** | **753** | 4 | 0 |
| `wrap` + `#meta` 加省略号 | 160 | 684 | 4 | 0（**没用**，因为 `white-space:nowrap` 撑住了） |

1. **`#meta` 是最大单一项，隐藏它省 69px**（160→91）。比压全部按钮效果好得多。
2. **给 `#meta` 加 `text-overflow:ellipsis` 没用** —— 它已经被 `header .meta{white-space:nowrap}`

3. **不 wrap 硬压是死路**（方案4：仍溢 180px），因为按钮总宽 + 标题 + 状态 就是超过 390。

```css
  header #meta { display: none; }          /* ← 关键，省 69px */

}
```
预计 headerH ≈ 91~100，聊天区 ≈ 750（原 794，仅 -5.5%），4 颗按钮全部可达。

> ⚠️ `#meta` 在桌面端是「模型 · 地址」状态条，手机上山看不到它也合理
> （手机上本来就不需要看模型地址）。**但这是产品决策，需主人确认**，不是我该定的。

### 根因（`ui-guard.mjs:219-224`）

- `_SEC_WORD` 挡 Security/安全/警告
- `_ASK_WORD` 挡 Confirm/确认/确定
- `_HARD_IRREVERSIBLE` **只挡 4 类**：清空回收站 / 格式化磁盘 / Empty Trash / Format Disk

**「删除 X」这个最常见的删除动作不在任何名单里** → 走文档豁免 → 放行。

### 修法（明天做）

```js
const _DELETABLE = /\b(files?|folders?|director(y|ies)|users?|accounts?|databases?|tables?|partitions?|disks?|drives?|programs?|apps?|applications?|photos?|pictures?|mails?|messages?|contacts?|bookmarks?)\b|文件|文件夹|目录|用户|账户|账号|数据库|数据表|分区|磁盘|硬盘|程序|软件|应用|照片|图片|邮件|消息|联系人|收藏|书签/i.test(s);
```
