### 4. POST 接口（隔离实例上打，不碰你的数据）

```bash
node _t_post.mjs
```

**为什么敢测 POST**：脚本自己起一个**独立实例**（`MINI_AGENT_DATA` 指向临时目录），
空 body 打一遍，跑完关掉、目录删掉。你正在用的那份一个字不动。

- 从 `server.mjs` 里自动抠出 **119 个 POST 路由**（不靠手抄）
- 实打 **107 个**，跳过 **12 个**（quit / restart / update / backup restore / QQ 登录 / 截屏）
- **5xx：0 个**

绝大多数返回 400/404/405 —— 说明**参数校验都在，没校验就崩的一个都没有**。
两个慢的单独放宽了时限，确认是"本来就慢"不是"卡死"：
`/api/selfcheck/run` 22.8 秒、`/api/voice-runtime/install` 43 秒，都 200。

### 5. 有副作用工具的「拒绝路径」

`say` / `spawn_worker` / `spawn_workers` / `tell_worker` / `send_file` / `make_image`
—— 不调正常路径（会出声、派活、花钱），只测**该被拒的时候拒没拒**。

顺手修了一个不一致：`say` / `make_image` / `send_file` 拒绝时**不带 `ERROR：` 前缀**，
而 `spawn_*` / `tell_worker` 带。同样是被拒，模型收到的信号却不一样。
现在统一了 —— 被拒就是 `ok:false` + `ERROR：`，一个口径。

### 6. 办事模式 + 智能体系统（隔离实例，15 项全过）

```bash
node _t_agents2.mjs
```

| 组 | 检查 | 结果 |
|---|---|---|
| 办事模式 | 功能开关打开 → 查状态 → 开会话内开关 → 读回 → 关 | ✔ 5/5 |
| 智能体 | 列表 / 新建 / 改名 / 设颜色 / 静音 / 删除后真的没了 | ✔ 6/6 |
| 群聊 | 查状态 / 把某个智能体拉进群 / 读回 | ✔ 3/3 |

**顺带确认了一条关键链路**：办事模式受 `features` 里 `taskmode` 这个开关管，
开关不开接口直接 403（"这个功能在【功能】里是关的"）。

这解释了为什么之前**点办事模式也没反应**——`/api/features` 因为那段注释返回 404，
前端拉不到功能列表，`taskmode` 永远是关的，办事模式自然开不了。**一个注释 bug 同时废了三个入口。**

另外记一笔坑：`/api/features/set` 的参数是 `enabled`，不是 `on`。
我第一版测试传了 `on`，接口静默接受但不生效（`setFeature(fid, undefined)`）。
前端传的是对的，但这类"参数名不一致还静默通过"的地方，以后容易踩。

## 二、没覆盖（写清楚，不装）

| 范围 | 为什么没测 | 怎么补 |
|---|---|---|
| 139 个 POST 接口 | 几乎全都有副作用（改设置、删会话、发消息） | 用临时会话 + 改完还原，或你手点一遍 |
| 其余写类工具（say / make_image / spawn_* / send_file） | 会出声、花钱、派活、推卡片 | 你手测 |
| QQ 接入 | 要真登录一个 QQ 号 | 你那边有号的时候测 |
| 移动端配对 | 要真手机连 | 扫码试一次 |
| 浏览器 / 视频 / 截图工具 | 要真实浏览器和素材 | 用 /api 或工具各跑一次 |
| 多 agent 群聊协作 | 要几个 agent 同时说话 | 开群聊压一轮 |
| 皮肤 / 语音 / TTS | 涉及声音和设备 | 你听着办 |

**这些不是"没问题"，是"没测"。** 区别很重要。

## 三、能保证什么

- 所有**只读路径**（看数据、查状态、列清单）没有坏的。
- 界面上**用户天天碰的那几条**（发送/停止/复制/图片/长文/表格/历史回翻）在真浏览器里验过。
- 已知的 30 条缺陷**一条不剩**，且每条都有原因为什么修、为什么没修。

**不能保证**：写操作在异常路径下的表现、外网服务（QQ/GitHub/模型网关）的稳定性、
以及"她真的变好用了"——这个只有你跑几轮才知道。

## 四、跑法

```bash
node scripts/run-all-checks.mjs     # 全套：静态检查 + 真机 + 接口 + 工具
node scripts/run-all-checks.mjs --no-ui   # 不跑真机那三趟（App 没开时用）
```

App 没开时，真机/接口/工具三趟会**明确打印"跳过"**，不会装作通过。
