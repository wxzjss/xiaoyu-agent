## 二、武器 id（`G.WEAPONS`）

**14 种基础武器**（都能升到 Lv8）：

| id | 名字 | 玩法 |
|---|---|---|
| `harpoon` | 鱼叉 | 朝最近敌人投直线枪，穿透 |
| `bubble` | 泡沫球 | 缓慢漂浮的追踪泡，命中爆炸小范围 |
| `anchor` | 沉锚 | 围绕自身旋转的重锚，撞到就伤 |
| `eel` | 电鳗 | 闪电链，打到一个人跳到下一个 |
| `urchin` | 海胆 | 向四周 360° 抛射尖刺 |
| `sonar` | 声呐 | 以自身为圆心的扩散脉冲圈 |
| `ink` | 墨汁 | 朝敌人丢一滩墨池，持续伤害 |
| `tide` | 潮汐 | 向朝向推出一道横推波浪，击退 |
| `pearl` | 珍珠 | 弹跳子弹，撞墙/敌人反弹 |
| `lance` | 骨枪 | 朝最近敌人捅一根超长骨矛，高伤 |
| `swarm` | 鱼群 | 放出一群小鱼追踪敌人 |
| `aura` | 寒气 | 身周常驻寒气光环，持续伤害 + 减速 |
| `chain` | 锁链 | 甩出锁链钩住敌人，把敌人拽向自己 |
| `whale` | 鲸歌 | 以自身为中心的巨型冲击波，击退大伤高，冷却长 |

**8 种进化形态**（写在同一个数组里，字段 `evoBase: '<基础id>'`，`maxLv: 1`，不进随机池）：

| id | 名字 | 由谁进化 |
|---|---|---|
| `harpoon_evo` | 深渊巨叉 | harpoon + `p_power` 满级 |
| `bubble_evo` | 泡狱 | bubble + `p_amount` 满级 |
| `anchor_evo` | 镇海锚 | anchor + `p_area` 满级 |
| `eel_evo` | 雷渊 | eel + `p_crit` 满级 |
| `urchin_evo` | 千棘 | urchin + `p_cd` 满级 |
| `sonar_evo` | 共鸣 | sonar + `p_duration` 满级 |
| `ink_evo` | 墨海 | ink + `p_area` 满级 |
| `whale_evo` | 万鲸共鸣 | whale + `p_luck` 满级 |
