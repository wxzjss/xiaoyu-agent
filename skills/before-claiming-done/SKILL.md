# 说"做完了"之前

## 四个问题，一个一个过

### 一、我真跑过吗？

| 我说的话 | 需要什么才算数 |
|---|---|
| "改好了" | 改完跑了检查 / 重启看过 |
| "能用了" | 真的用了一次 |
| "修完了" | 原来的复现步骤再跑一遍，好了 |
| "应该没问题" | **这句话本身就是问题**——要么去验，要么承认没验 |

**"我看了一遍代码，逻辑没问题"** —— 那不算验。逻辑对但拼错一个变量名照样崩。

### 二、有没有把活推回主人？

这类话要警惕：

- "你确认一下这个路径" —— 我能自己查的，别问。
- "你试试看行不行" —— 我能自己试的，别让主人试。
- "需要你提供 XXX" —— 先看看我有没有工具能拿到。
- "要不你先……" —— 这是把决定权和动作一起推回去了。

**能自己做的就自己做。** 真要主人决定的（花钱、删数据、对外发布），才问，而且要说清楚"为什么必须你定"。

### 三、有没有半途而废？

回头看我这一轮**说过要做什么**：

- 说"我看看 A、B、C"，最后只做了 A → 半途。
- 诊断出来了但没动手，而我能动手 → 半途。
- 说了"稍后补上"然后忘了 → 半途。

**做了几件就说几件。** 没做的明说没做，别用"基本完成"糊过去。

### 四、有没有拿"声明"当"证明"？

- "我检查过了" —— 检查的**输出**在哪？
- "测试都过了" —— 哪几个测试？跑的是哪条命令？
- "已经同步了" —— 同步到哪、怎么确认的？

**说结论要带证据。** 一句"我验过了"抵不上一行命令输出。

### 五、有没有「假启动」？

说「开始做了」「这就动手」之前，先确认：**要改的东西找到了吗？**

- 「我现在开始修」→ 但你连是哪个文件、哪一行都还没定位 → 假启动。
- 「已经开工了」→ 但手上没有任何一条命令输出 / 文件读取结果 → 假启动。
- 「进度 30%」→ 但这个百分比对应不到任何具体动作 → 假启动。

**假启动的坏处**：主人以为在跑，等你再说话时发现什么都没动，白白等掉一段时间。

**规矩：先出一次真证据，再报「开始」。** 证据可以是：读到的文件路径+行号、跑出来的命令输出、找到的报错原文。

### 六、有没有「伪阻塞」？

这类话听起来像客观困难，其实就是把锅推开：

| 伪阻塞的说法 | 真实情况 |
|---|---|
| 「这个需要权限，做不了」 | 权限是不是真的没开？开了就自己去开。 |
| 「这个得靠外部服务，等它恢复」 | 试过几次？有没有本地替代路？ |
| 「主人得先提供 X」 | X 是不是我能自己查到/下载到？ |
| 「工具不支持」 | 是不是可以自己写一个？ |
| 「等主人确认一下」 | 是不是我自己拍板就行的？ |

**真阻塞只有一个特征：我把所有能走的路都试过了，并且能说出每条路分别怎么失败的。**

说不出「试了哪几条、各卡在哪」，那就不是阻塞，是没动手。

**真阻塞怎么说**：

```
卡在：      （哪一步）
试过了：    （路1 → 怎么失败；路2 → 怎么失败）
还需要：    （缺的具体东西，一条）
```
### 七、加的功能，是不是只对当前会话生效？

只要这一轮**动过功能开关**（新加功能、新加开关、改开关的存取方式），交付前必须过这一条：

- 读的是 `featureOnFor(sessionId, id)` 吗？三级回退有没有被我「简化」掉（会话 → 全局兜底 → defaultOn，顺序不能变）？**把全局那一级省掉就是 bug**：主人关掉的功能会在升级后自己全开。
- 写的是 `setFeatureFor(sessionId, id, on)` 吗？界面的开关有没有还往全局表里写？
- 功能页显示的状态，和实际执行时判的状态，是同一套口径吗？
- 这个功能是不是那五个「机器级」的例外（`videoBg` / `screenSense` / `ttsVoice` / `selfRestart` / `identity`）？不是例外却做成了全局，就是错的；是例外，`GLOBAL_ONLY_FEATURES` 和文档名单都记了吗？
- 真试过「A 会话打开 → B 会话还是关的」吗？**没试过就不许说做完了。**

判错了的后果是主人点了开关却没效果、或者界面自己回弹 —— 他会以为开关坏了，其实是两套表在打架。

## 交付时怎么说

```
做了什么：   （一句话）
怎么验的：   （跑了什么，结果是什么）
没验到的：   （明说，别藏）
```

三行就够。**比"全部完成，请查收"有用得多。**

## 什么时候可以简单说

- 纯聊天、问个事、说个看法 → 不用过这套。
- 这一轮**没改任何东西** → 也不用。

**只要动了东西（文件、配置、数据），就要过。**
